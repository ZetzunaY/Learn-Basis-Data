# Praktikum Basis Data - MySQL / MariaDB

Repositori ini berisi kumpulan tugas, eksplorasi, dan penyelesaian studi kasus untuk mata kuliah Basis Data di program studi Informatika, Universitas Singaperbangsa Karawang (UNSIKA). Seluruh *query* dan perancangan skema dieksekusi menggunakan *Command Line Interface* (CLI) pada lingkungan XAMPP.

# Struktur Repositori & Cakupan Materi

- **Chapter 1: SQL Fundamentals & Administration**
  - Pengenalan dasar DQL (`SELECT`), fungsi manipulasi *string* (`CONCAT`, `LENGTH`, `LEFT`, `RIGHT`, `REPLACE`), fungsi waktu, dan manajemen *user* CLI (`CREATE USER`, `DROP USER`).
- **Chapter 2: Data Definition Language (DDL) & Basic Tables**
  - Perancangan basis data dasar, pemahaman tipe data (*String*, *Numeric*, *Date/Time*), serta pembuatan dan penghapusan tabel awal.
- **Chapter 3: Relational Database, Foreign Keys, & ALTER TABLE**
  - Penerapan relasi *parent-child* menggunakan `FOREIGN KEY`, penggunaan tipe data terbatas (`ENUM`), serta manipulasi struktur tabel lanjutan menggunakan `ALTER TABLE` (`ADD`, `CHANGE`, `DROP`).

# Tech Stack
- **Database Engine:** MySQL / MariaDB (via XAMPP)
- **Tools:** Command Line Interface (CLI), Cursor / VS Code, Git & GitHub
